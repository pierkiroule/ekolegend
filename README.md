# La légende d’Eko

MVP React + Vite pour une expérience de médiation narrative autour de l’identité numérique.

## Fonctionnalités

- Parcours de 7 cyber-fossiles et sagesses associées.
- Sauvegarde locale de la collection avec `localStorage`.
- Export de l’archive en JSON ou en synthèse TXT.
- Interface responsive, mobile-first, sans dépendance CSS externe.

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Structure

- `src/App.jsx` orchestre les vues principales et la persistance.
- `src/data/archetypes.js` centralise le contenu narratif.
- `src/components/` contient les composants UI réutilisables.
- `src/styles.css` définit le design system du MVP.
